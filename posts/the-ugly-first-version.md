There is a strange moment when you're building something where you know exactly what it *could* look like, but what you have in front of you looks nothing like it.

That's normal.

The first version is allowed to be ugly.

## Ship the rough version

A rough version gives you something that a blank screen cannot: **feedback**.

You can use it. Break it. Show it to someone. Figure out what matters.

You can't do any of that with an idea sitting in your head.

So make the button ugly.

Use the default font.

Write the terrible code.

Then improve it.

The first version only has one job:

**exist.**
