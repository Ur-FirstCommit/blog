The easiest way to get better at building is to build something you can actually finish.

Not the next social network. Not a billion-dollar startup. Not an operating system from scratch.

Something small.

## Give yourself a finish line

Build a calculator. A timer. A tiny game. A weird API. A CLI tool that does one ridiculous thing.

The point isn't the project.

The point is getting through the entire loop:

`idea → code → bug → fix → ship`

That loop is where the learning happens.

## Then make it slightly harder

Once you finish one thing, make the next project just a little more ambitious.

That's how a collection of tiny projects turns into real experience.
