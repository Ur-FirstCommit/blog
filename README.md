# FirstCommit Blog

A custom Jekyll blog designed for FirstCommit.

### Deploy to GitHub Pages
1. Upload these files to a GitHub repository.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Add `blog.firstcommit.xyz` under Custom domain.
4. Add a DNS CNAME: `blog` → `YOUR_USERNAME.github.io`.
5. Enable Enforce HTTPS.
